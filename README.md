# Concurrent Java Programming Projects

## Overview

This repository contains a collection of Java concurrency and multithreading projects developed during academic learning exercises.

The projects demonstrate practical implementation of:
- Java threads
- Synchronization primitives
- Shared resource coordination
- Concurrent simulations
- Blocking queues
- Atomic operations
- Thread-safe architecture patterns

Each subproject focuses on different concurrency challenges and system-design concepts.

---

## Included Projects

### Concurrent Farm Simulation
A multithreaded Java simulation that models farm entities such as sheep, dogs, gates, and grid cells operating concurrently inside a shared environment.

### Concurrent Order Simulation
A concurrent restaurant/order-processing simulation that demonstrates producer-consumer workflows, inventory coordination, and multithreaded order preparation.

### Thread Scheduler Simulation
A virtual machine and scheduler simulation focused on thread execution, logging systems, and concurrent process handling.

### Spacecraft Threading Simulation
A spacecraft control simulation implementing multiple concurrent subsystems such as propulsion, communication, and oxygen generation.

### Simulation Exercise
A concurrency-focused simulation exercise demonstrating atomic operations, state management, and multithreaded execution flows.
